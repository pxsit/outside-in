## คำอธิบายโครงงาน

**Outside In** เป็นโครงงานคอมพิวเตอร์ที่พวกเราตั้งใจทำขึ้นเพื่อช่วยให้เพื่อนๆ เข้าใจระบบต่างๆ ในร่างกายมนุษย์ได้ง่ายขึ้น โดยไม่ต้องท่องจำจากหนังสือเพียงอย่างเดียว เราใช้การเขียนโค้ดสร้างภาพเคลื่อนไหวและแบบทดสอบเพื่อให้การเรียนสนุกขึ้นครับ

## วัตถุประสงค์

1. พัฒนาเว็บไซต์ที่นำเสนอองค์ความรู้เกี่ยวกับโครงสร้างของร่างกายมนุษย์
2. ส่งเสริมการเรียนรู้ Anatomy ด้วยวิธีที่เข้าใจง่ายและน่าสนใจ
3. ให้ผู้ใช้งานสามารถสำรวจระบบต่างๆ ในร่างกายอย่างมีลำดับขั้น
4. ฝึกทักษะการออกแบบและพัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript

## ระบบที่ครอบคลุม

1. **ระบบผิวหนัง** - เรียนรู้เกี่ยวกับผิวหนังและหน้าที่ป้องกันร่างกาย
2. **ระบบกล้ามเนื้อ** - ทำความเข้าใจกล้ามเนื้อและการเคลื่อนไหว
3. **ระบบกระดูก** - ศึกษาโครงสร้างกระดูกและข้อต่อ
4. **ระบบไหลเวียนเลือด** - ทำความเข้าใจการไหลเวียนของเลือด

## ฟีเจอร์หลัก

- **บทเรียน 4 ระบบหลัก**: ไหลเวียนเลือด, ประสาท, หายใจ และน้ำเหลือง
- **Interactive Learning**: เรียนรู้ผ่านภาพเคลื่อนไหวและการโต้ตอบกับหน้าจอ
- **Quiz Game**: แบบทดสอบท้ายบทเรียนเพื่อวัดความเข้าใจ
- **Responsive**: เปิดดูได้ทั้งในคอมพิวเตอร์และมือถือ

## เทคโนโลยีที่ใช้

- **HTML5** - โครงสร้างเว็บไซต์
- **CSS3** - การออกแบบและ animation
- **JavaScript ES6+** - ฟังก์ชันการทำงาน
- **GSAP** - ไลบรารีช่วยทำ Animation ให้ดูลื่นไหล
- **JSON**: เก็บข้อมูลข้อสอบแยกเป็นหมวดหมู่เพื่อให้แก้ไขง่าย
- **AI**: ใช้ Gemini 3 Pro และ Claude 4.5 Sonnet ในการแก้ไขข้อผิดพลากต่างๆ

## การใช้งาน

1. **หน้าแรก** - ดูภาพรวมและคลิกเริ่มการสำรวจ
2. **ส่วน Hero** - hover หรือคลิกที่ชั้นต่างๆ ของร่างกาย
3. **ส่วนระบบ** - คลิกที่การ์ดแต่ละระบบเพื่อเรียนรู้
4. **Modal ข้อมูล** - อ่านข้อมูล ดูรูปภาพ และทำแบบทดสอบ
5. **Quiz** - ทดสอบความเข้าใจและดูผลคะแนน
